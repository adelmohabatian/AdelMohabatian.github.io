# WebSocial v1.3
Full lightweight static site for GitHub Pages. English default, Persian available throughout.

## Deployment
Rename this archive to `site.zip`, replace `releases/site.zip` in the repository and commit. Existing workflow extracts and publishes the complete archive.

## Media policy
No PDF articles, large photographs, or original video are bundled. The publishing workflow replaces the entire site, so removed PDFs will not remain hosted after deployment. DOI links are preserved.

## Content integrity
English titles and descriptions of books are editorial translations pending final publisher metadata verification. No unverified film credits or festival selections have been added.
